# terraform-provider-infrawrench

The Terraform provider for [Infrawrench](https://infrawrench.com) organization
configuration: budgets, cost centres, allocation rules, saved reports and
filters, alert routing, monitoring, lifecycle governance, connected accounts and
access control.

## This repository is a mirror

Do not open pull requests here and do not edit these files. The provider is
developed in the Infrawrench monorepo under `terraform-provider-infrawrench/`,
and this repository's tree is replaced wholesale on every release, workflows
included. It exists because the Terraform Registry resolves a provider to a
dedicated public repository named `terraform-provider-{NAME}` and reads its
releases from tags, which a monorepo subdirectory cannot satisfy.

The full README, usage and resource documentation arrive with the first release.
